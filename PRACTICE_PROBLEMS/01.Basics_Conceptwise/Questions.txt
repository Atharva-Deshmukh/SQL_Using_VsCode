SQL PRACTICE WORKBOOK — SDET-2 / 20 LPA

HOW TO USE
-----------
1. Read/create the tables for the current section.
2. Solve PROBLEMS without looking at the solution key.
3. Run your query in MySQL.
4. Compare with EXPECTED OUTPUT.
5. Only then inspect the solution.

The datasets are intentionally small (4–5+ rows) but contain:
- NULLs
- duplicate values
- unmatched rows
- multiple departments
- multiple dates
- values useful for ranking/window functions
