MUST KNOW:

Also know:

SUM() OVER(...)
AVG() OVER(...)
COUNT() OVER(...)

Core patterns:

-- Rank within group
RANK() OVER(
    PARTITION BY department
    ORDER BY salary DESC
)

-- Previous row
LAG(value) OVER(
    ORDER BY date
)

-- Next row
LEAD(value) OVER(
    ORDER BY date
)

-- Running total
SUM(value) OVER(
    ORDER BY date
)

IMPORTANT:

ROW_NUMBER → unique numbering
RANK       → ties + gaps
DENSE_RANK → ties + no gaps

This section should be one of your strongest.

⚠️ 6. NULL HANDLING + ANTI-JOIN + EDGE CASES
   Real-world SQL correctness
====================================================================

MUST KNOW:

IS NULL
IS NOT NULL
COALESCE()
NULLIF()

CRITICAL:

NULL = NULL      → NOT TRUE
NULL <> value    → NOT TRUE

Use:

WHERE column IS NULL

NOT:

WHERE column = NULL

Also master:

LEFT JOIN + WHERE right_table.id IS NULL

This is the classic ANTI-JOIN pattern.
